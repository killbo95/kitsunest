# KitsuNest — Anime Discovery Guide

A responsive, single-file anime catalogue prototype. It includes search, genre filters, series cards, and sample episode-guide dialogs.

## Publish
This file is in the `kitsunest/` folder of the `killbo95.github.io` repository. If GitHub Pages is enabled for that repository and serves from the root of `main`, the expected site URL is:

https://killbo95.github.io/kitsunest/

## Notes
- This is a discovery guide, not a video host. Episode lists are sample data and do not contain playable streams.
- Add links only to official streams or sources you have permission to share or embed.
- Poster designs are CSS placeholders, not official anime artwork.
- Verify series details and episode counts before publishing.
